## 🧠 Sobre mí

Soy estudiante de **Análisis y Desarrollo de Software en el SENA** y me enfoco en el desarrollo backend y full stack. Me gusta convertir ideas en aplicaciones funcionales, con código limpio y bases de datos bien diseñadas.

- 🌱 Fortaleciendo backend con **C# / .NET y Node.js**
- 💻 Construyendo interfaces con **React y TypeScript**
- 🗄️ Diseñando bases de datos en **SQL Server, PostgreSQL y MySQL**
- 🤖 Explorando **IA aplicada** y despliegue en la nube
- 🎯 Meta: trabajar como desarrollador de software en un equipo donde siga creciendo
