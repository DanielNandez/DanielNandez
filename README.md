## Sobre mí

Soy estudiante de **Análisis y Desarrollo de Software en el SENA**, enfocado en fortalecer mis habilidades dentro del desarrollo de aplicaciones y la ingeniería de software.

Me interesa construir soluciones digitales funcionales, escalables y fáciles de mantener. Actualmente desarrollo mis conocimientos en **backend, frontend, inteligencia artificial y tecnologías cloud**, trabajando con diferentes herramientas para comprender el ciclo completo de creación de una aplicación.

Mi objetivo es seguir creciendo como desarrollador de software, participar en proyectos significativos y aplicar buenas prácticas de programación, diseño de sistemas, control de versiones y trabajo colaborativo.

### Áreas de interés

- Desarrollo backend
- Desarrollo frontend
- Desarrollo full stack
- Inteligencia artificial
- Tecnologías cloud
- Bases de datos
- APIs y servicios web
- Automatización y DevOps

**Open to:** oportunidades de aprendizaje · proyectos colaborativos · desarrollo de software · open source
